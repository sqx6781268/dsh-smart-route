# 配置说明

目的：为需要手工调整高级规则的用户提供说明。适用于多链路由 0.1.0 至 0.1.3（配置格式未变，仍为版本 1）；字段改变时同步维护示例与 Schema。0.1.3 新增的图片路由行为不涉及配置字段，见 [图片路由](#图片路由)。

从 examples/chains.json 复制示例后，把所有 your- 开头的占位成员替换为自己 DSH 中真实可用的渠道与模型。不要把密钥写进配置。

## 链

`chains` 是链列表。每条含唯一 `id`、显示 `name`、`models` 成员数组；`enabled:false` 临时停用而不删除。成员支持 `provider/model` 字符串或 `{ "provider": "your-provider", "model": "your-model" }` 对象。字符串只按第一个斜杠分隔。

`strategy` 默认 `fallback`，每次从链头尝试；`round-robin` 按轮次更换起点。`stickyLimit` 为轮转时连续使用同一起点的次数，正整数，默认 1。

## 降级规则

`policy.mode` 为 `all`（默认所有错误）、`only`（只对 codes 中的码）或 `all-except`（排除 codes 中的码）。`neverCodes` 优先于模式，缺省保留 ABORTED 与 CONTEXT_WINDOW_EXCEEDED；显式空数组表示覆盖默认码表，但用户主动取消始终停止。已开始回答后不再降级。

例如只对服务器错误切换：`"policy": { "mode": "only", "codes": ["SERVER"] }`。未知异常按其归一化错误码参与规则，不匹配 only 时停止，避免异常通道绕过用户配置。

## 冷却

`policy.cooldown` 默认启用，可写 false 关闭；对象支持 `enabled`、毫秒时长 `ms`、错误 `codes`、匹配方式 `match`（exact 或 contains）。默认五分钟，码为 AUTH、INVALID_CREDENTIAL、QUOTA、QUOTA_EXCEEDED、ACCOUNT_QUOTA。超时与服务器暂时故障不在默认冷却中。

## 图片路由

目的：说明当前实现对图片请求的判断规则与已知边界，避免把它理解成"链会自动帮你选一个能看图的成员"。本节描述的是 **0.1.3 起的当前行为**；配置格式没有因此改变（仍为版本 1），也没有新增任何字段。

### 判定规则

- **视觉成员**：只有当成员的模型信息里 `inputModalities` **同时包含** `text` 与 `image` 时，才算"能看图"。只声明 `image`（纯图像输入）、只声明 `text`，或能力解析失败/未知的成员，都**不**算视觉成员。插件不提供手工覆盖开关。
- **链的声明**：链里只要有一个成员本次声明同时含 `text` 与 `image`，链就对宿主宣称支持 `text + image`；否则宣称 `text`。非 `image` 模态沿用成员交集规则，不会被"凡不是图片就当作文本"改写（例如成员都只声明 `audio` 时，链如实声明 `audio`，不会伪装成 `text`）。
- **含图片的请求**：只委派给视觉成员，并保持它们原来的相对顺序。纯文本成员在这次请求里被跳过，状态页的「图片筛选」列会显示跳过的是谁（原因码 `NO_VISION`）。纯文本请求不进入这条筛选，候选顺序、降级与冷却与以前一致。
- **没有视觉成员时**：链直接给出终态错误（原因码 `NO_VISION_MEMBER`，消息里点名链与"没有成员同时声明支持文本与图片"），**不委派**任何成员、**不**把图片转成文字、也**不**改用纯文本成员。若请求还没发出，宿主本身会先以 `MODEL_DOES_NOT_SUPPORT_IMAGES` 拒绝。
- **冷却**："全员冷却就仍全试"的兜底只作用于**已筛出的视觉成员**；含图片的请求不会因为兜底而引入纯文本成员。
- **图片预算**：插件不自带图片数量/字节预算，也不做缩放或重编码；这些由成员自己执行。成员要求卸载图片时（`IMAGE_OFFLOAD_REQUIRED`），插件把该失败连同卸载数量原样交给宿主，由宿主卸载后重试，不降级、不进冷却。

### 已知边界（不可承诺的部分）

- **纯文本链看不到历史图**：给一条不宣称图片的链发请求时，宿主在插件执行**之前**就把历史图片块替换成占位文本（`[image omitted because this model accepts text only; attachment sha256:…]`）。插件收到时已无原图，检测不到也无法恢复。所以"多轮会话里继续用历史图片"只能通过**声明了图片能力的链**实现。
- **混合链必须宣称图片**：否则宿主同样会投影历史图，链里的视觉成员永远收不到图。代价就是上面说的、有图请求中纯文本成员被筛掉。
- **未做真机验证**：当前只完成离线（桩宿主 + 桩成员）验证，未对真实服务商发过图片请求，因此**不宣称**任何具体模型或渠道实际能看图，也**不宣称**真机视觉成功。真实接受度请自行用该模型单独试。

完整需求条目（R1–R12、B1–B4）与逐格测试矩阵（M1–M27）见 [图片路由契约](图片路由契约冻结.md)。

## 文件版本

`version` 当前为 1，省略按 1 读取；未知版本拒绝。可选 `$schema` 指向 src/chains.schema.json 以获得编辑器提示，不参与联网加载。配置页面同时提供 `/multi-chain/chains.schema.json`。

手工写文件出现格式错误时请先恢复备份；网页保存会严格检查，避免悄悄丢失成员。两个页面同时编辑必须处理保存冲突，不能使用旧草稿覆盖新文件。
