# 配置说明

目的：为需要手工调整高级规则的用户提供说明。适用于多链路由 0.1.0 至 0.1.2（配置格式未变，仍为版本 1）；字段改变时同步维护示例与 Schema。

从 examples/chains.json 复制示例后，把所有 your- 开头的占位成员替换为自己 DSH 中真实可用的渠道与模型。不要把密钥写进配置。

## 链

`chains` 是链列表。每条含唯一 `id`、显示 `name`、`models` 成员数组；`enabled:false` 临时停用而不删除。成员支持 `provider/model` 字符串或 `{ "provider": "your-provider", "model": "your-model" }` 对象。字符串只按第一个斜杠分隔。

`strategy` 默认 `fallback`，每次从链头尝试；`round-robin` 按轮次更换起点。`stickyLimit` 为轮转时连续使用同一起点的次数，正整数，默认 1。

## 降级规则

`policy.mode` 为 `all`（默认所有错误）、`only`（只对 codes 中的码）或 `all-except`（排除 codes 中的码）。`neverCodes` 优先于模式，缺省保留 ABORTED 与 CONTEXT_WINDOW_EXCEEDED；显式空数组表示覆盖默认码表，但用户主动取消始终停止。已开始回答后不再降级。

例如只对服务器错误切换：`"policy": { "mode": "only", "codes": ["SERVER"] }`。未知异常按其归一化错误码参与规则，不匹配 only 时停止，避免异常通道绕过用户配置。

## 冷却

`policy.cooldown` 默认启用，可写 false 关闭；对象支持 `enabled`、毫秒时长 `ms`、错误 `codes`、匹配方式 `match`（exact 或 contains）。默认五分钟，码为 AUTH、INVALID_CREDENTIAL、QUOTA、QUOTA_EXCEEDED、ACCOUNT_QUOTA。超时与服务器暂时故障不在默认冷却中。

## 文件版本

`version` 当前为 1，省略按 1 读取；未知版本拒绝。可选 `$schema` 指向 src/chains.schema.json 以获得编辑器提示，不参与联网加载。配置页面同时提供 `/multi-chain/chains.schema.json`。

手工写文件出现格式错误时请先恢复备份；网页保存会严格检查，避免悄悄丢失成员。两个页面同时编辑必须处理保存冲突，不能使用旧草稿覆盖新文件。
